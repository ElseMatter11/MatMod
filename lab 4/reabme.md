### Отчет по лабораторной работе: Численное исследование законов геометрической оптики

**Объект исследования:** Распространение светового луча в плоской слоистой среде при наличии отражающей и преломляющей границ раздела.

**Задача:**   
1. Для закона отражения: определить точность попадания луча в приемник при различных начальных параметрах (угол падения, положение источника и приемника). Вычислить значение вариационной переменной (угла падения), при котором луч попадает в приемник.  
2. Для закона преломления: определить точность попадания луча в приемник при различных начальных параметрах (угол падения, показатели преломления сред). Вычислить значение вариационной переменной (угла падения), при котором луч попадает в приемник после преломления.

---

### 1. Содержательная постановка задачи

Источник света испускает луч в сторону плоской границы раздела двух сред (или отражающей поверхности). На некотором расстоянии от границы расположен приемник (детектор) света. Требуется определить, при каком угле падения $\theta$ луч, отразившись или преломившись, попадет точно в центр приемника. Поскольку аналитическое решение для произвольных координат источника и приемника может быть громоздким, задача решается численно: путем варьирования угла $\theta$ (вариационная переменная) и минимизации расстояния между точкой падения луча на плоскость приемника и его центром. Также исследуется, как точность попадания зависит от величины отклонения угла от оптимального значения.

### 2. Концептуальная постановка задачи

Рассматривается двумерная плоскость XY. Отражающая или преломляющая граница — это прямая линия (например, $y = 0$). Источник $S$ и приемник $D$ расположены в одной полуплоскости (для отражения) или в разных (для преломления). Луч выходит из $S$ под углом $\theta$ к нормали, взаимодействует с границей по известным законам и распространяется далее прямолинейно до пересечения с плоскостью $y = y_D$, где расположен приемник. Вариационная переменная $\theta$ — угол падения луча на границу. Критерий попадания — координата $x$ точки пересечения луча с плоскостью приемника $x_{hit}$ должна совпасть с $x_D$. Задача сводится к решению уравнения $f(\theta) = x_{hit}(\theta) - x_D = 0$ численным методом.

### 3. Математическая постановка задачи

**Общие параметры:**
*   $S(x_S, y_S)$ — координаты источника.
*   $D(x_D, y_D)$ — координаты центра приемника.
*   Граница раздела — прямая $y = 0$.

**Закон отражения:**
*   Угол падения равен углу отражения: $\theta_1 = \theta_2 = \theta$.
*   Источник и приемник находятся в одной среде ($y_S > 0$, $y_D > 0$).
*   Луч выходит из $S$, падает в точку $P(x_P, 0)$, отражается и попадает в плоскость приемника $y = y_D$.
*   Точка $P$: $x_P = x_S + y_S \tan\theta$.
*   После отражения луч идет под углом $-\theta$ к нормали.
*   Координата попадания в плоскость приемника $y = y_D$:
    $$x_{hit} = x_P + y_D \tan\theta = x_S + (y_S + y_D) \tan\theta$$
*   Условие попадания в приемник: $x_{hit} = x_D$.
*   Отсюда оптимальный угол: $$\tan\theta_{opt} = \frac{x_D - x_S}{y_S + y_D}$$

**Закон преломления (Снеллиуса):**
*   $n_1 \sin\theta_1 = n_2 \sin\theta_2$, где $n_1$ — среда источника, $n_2$ — среда приемника.
*   Источник в среде $n_1$ ($y_S > 0$), приемник в среде $n_2$ ($y_D < 0$).
*   Вариационная переменная — угол падения в первой среде $\theta_1$.
*   Точка падения: $x_P = x_S + y_S \tan\theta_1$.
*   Угол преломления: $\theta_2 = \arcsin\left(\frac{n_1}{n_2} \sin\theta_1\right)$, при условии $n_1 \sin\theta_1 \le n_2$ (нет полного внутреннего отражения).
*   После преломления луч идет в среде $n_2$ от точки $P$ вниз до $y = y_D$ ($y_D < 0$).
*   Расстояние от $P$ до плоскости приемника по вертикали: $|y_D| = -y_D$.
*   Координата попадания:
    $$x_{hit} = x_P + (-y_D) \tan\theta_2 = x_S + y_S \tan\theta_1 - y_D \tan\theta_2$$
*   Уравнение для угла $\theta_1$: $$f(\theta_1) = x_S + y_S \tan\theta_1 - y_D \tan\left[\arcsin\left(\frac{n_1}{n_2}\sin\theta_1\right)\right] - x_D = 0$$

Аналитически разрешить уравнение для $\theta_1$ относительно $\theta_1$ сложно, поэтому применяется численный метод нахождения корня.

### 4. Качественный анализ и проверка корректности модели

**Допущения:**
*   Среды однородные и изотропные, лучи — прямые линии.
*   Источник — точечный, приемник также точечный (или его размер много меньше расстояния, можно анализировать попадание в центр).
*   Граница раздела — идеальная плоскость.

**Проверка корректности:**
*   Для отражения существует единственное решение (оптимальный угол) при условии, что $x_D$ находится в зоне досягаемости отраженного луча.
*   Для преломления решение существует, только если $n_1 \sin\theta_1 \le n_2$. При заданных $n_1 < n_2$ и достаточно большом смещении $x_D - x_S$ угол $\theta_1$ может выйти за пределы области определения арксинуса (полное внутреннее отражение), и тогда решения не будет.
*   Численная модель легко проверяется подстановкой найденного угла в аналитическую формулу для отражения.

### 5. Выбор и обоснование методов решения

Для нахождения угла $\theta$, при котором $x_{hit} = x_D$ (вариационная переменная), используется численный метод решения нелинейного уравнения:
$$f(\theta) = x_{hit}(\theta) - x_D = 0$$
Выбран метод **бисекции (деления пополам)**, так как:
*   Функция $f(\theta)$ монотонна и непрерывна на допустимом интервале углов (для отражения — линейна, для преломления — монотонно возрастает).
*   Метод гарантирует сходимость и прост в реализации.
*   Границы интервала задаются физическими ограничениями: $0 \le \theta \le \pi/2$ для отражения и $0 \le \theta_1 \le \arcsin(n_2/n_1)$ для преломления.

Для исследования точности попадания: задается погрешность угла $\Delta\theta$, вычисляется $x_{hit}(\theta_{opt} \pm \Delta\theta)$ и определяется абсолютное отклонение от $x_D$.

### 6. Аналитический (численный) метод

Реализуем вычисления и визуализацию в Python.

```python
import numpy as np
import matplotlib.pyplot as plt

"""
Общие координаты (пример)
"""
x_S, y_S = 0.0, 5.0   # Источник
x_D, y_D = 8.0, 3.0   # Приемник (для отражения)

"""
Функция для расчета x_hit при отражении
"""
def x_hit_reflection(theta, x_S, y_S, y_D):
    return x_S + (y_S + y_D) * np.tan(theta)

"""
Функция для расчета x_hit при преломлении
"""
def x_hit_refraction(theta1, x_S, y_S, y_D, n1, n2):
    x_P = x_S + y_S * np.tan(theta1)
    sin_theta2 = (n1 / n2) * np.sin(theta1)
    theta2 = np.arcsin(sin_theta2)
    return x_P + (-y_D) * np.tan(theta2)

"""
Численное решение уравнения x_hit(theta) = x_D методом бисекции
"""
def find_optimal_angle(func, x_target, bracket, tol=1e-8):
    a, b = bracket
    f_a = func(a) - x_target
    f_b = func(b) - x_target
    if f_a * f_b > 0:
        return None  # Корня в интервале нет
    while (b - a) / 2 > tol:
        c = (a + b) / 2
        f_c = func(c) - x_target
        if f_c == 0.0:
            return c
        if f_a * f_c < 0:
            b = c
            f_b = f_c
        else:
            a = c
            f_a = f_c
    return (a + b) / 2

"""
Задача 1: Закон отражения
"""
print("========== ЗАКОН ОТРАЖЕНИЯ ==========")

theta_opt_ref = find_optimal_angle(
    lambda th: x_hit_reflection(th, x_S, y_S, y_D),
    x_D,
    (0.0, np.pi/2 - 1e-4)
)

theta_opt_ref_analytical = np.arctan((x_D - x_S) / (y_S + y_D))

print("Численный оптимальный угол (град): {:.4f}".format(np.degrees(theta_opt_ref)))
print("Аналитический оптимальный угол (град): {:.4f}".format(np.degrees(theta_opt_ref_analytical)))
print("Совпадение: {:.6e}".format(abs(theta_opt_ref - theta_opt_ref_analytical)))

print("\nИсследование точности попадания:")
delta_theta_deg = np.linspace(-10, 10, 200)
delta_theta = np.radians(delta_theta_deg)
theta_varied = theta_opt_ref + delta_theta
x_hit_varied = x_hit_reflection(theta_varied, x_S, y_S, y_D)
deviation = x_hit_varied - x_D

plt.figure(figsize=(8, 5))
plt.plot(delta_theta_deg, deviation, 'b-')
plt.axhline(0, color='grey', linestyle='--')
plt.axvline(0, color='grey', linestyle='--')
plt.xlabel('Δθ от оптимального, градусы')
plt.ylabel('Отклонение x_hit - x_D, м')
plt.title('Закон отражения: точность попадания')
plt.grid(True, alpha=0.3)
plt.show()

"""
Задача 2: Закон преломления
"""
print("\n========== ЗАКОН ПРЕЛОМЛЕНИЯ ==========")

n1, n2 = 1.0, 1.5
y_D_refr = -3.0

theta_crit = np.arcsin(n2 / n1) if n1 > n2 else np.pi/2

theta_opt_refr = find_optimal_angle(
    lambda th: x_hit_refraction(th, x_S, y_S, y_D_refr, n1, n2),
    x_D,
    (1e-6, theta_crit - 1e-6)
)

if theta_opt_refr is None:
    print("При данных параметрах луч не попадает в приемник (возможно, полное внутреннее отражение).")
else:
    print("Оптимальный угол падения (град): {:.4f}".format(np.degrees(theta_opt_refr)))
    x_hit_opt = x_hit_refraction(theta_opt_refr, x_S, y_S, y_D_refr, n1, n2)
    print("x_hit при оптимальном угле: {:.6f} (цель = {:.2f})".format(x_hit_opt, x_D))

    print("\nИсследование точности попадания:")
    delta_theta1_deg = np.linspace(-5, 5, 200)
    delta_theta1 = np.radians(delta_theta1_deg)
    theta1_varied = theta_opt_refr + delta_theta1

    valid = theta1_varied < theta_crit
    deviation_refr = np.full_like(delta_theta1_deg, np.nan)
    x_hit_refr_varied = np.full_like(delta_theta1_deg, np.nan)

    for i, th in enumerate(theta1_varied):
        if valid[i]:
            x_hit_refr_varied[i] = x_hit_refraction(th, x_S, y_S, y_D_refr, n1, n2)
            deviation_refr[i] = x_hit_refr_varied[i] - x_D

    plt.figure(figsize=(8, 5))
    plt.plot(delta_theta1_deg, deviation_refr, 'r-')
    plt.axhline(0, color='grey', linestyle='--')
    plt.axvline(0, color='grey', linestyle='--')
    plt.xlabel('Δθ1 от оптимального, градусы')
    plt.ylabel('Отклонение x_hit - x_D, м')
    plt.title('Закон преломления: точность попадания')
    plt.grid(True, alpha=0.3)
    plt.show()

    if not np.all(valid):
        print("Предупреждение: часть углов выходит за критический угол ПВО.")

print("\nИсследование завершено.")
```

### 7. Проверка адекватности модели

**Выводы по результатам расчета:**

1.  **Закон отражения.** Численно найденное значение вариационной переменной (угла падения) с высокой точностью совпадает с аналитическим решением $\tan\theta_{opt} = (x_D - x_S)/(y_S + y_D)$. Это подтверждает корректность численного метода бисекции. Зависимость отклонения точки попадания от разности углов $\Delta\theta$ практически линейна в малом диапазоне, что соответствует разложению в ряд Тейлора.

2.  **Закон преломления.** Численный метод позволил найти оптимальный угол падения даже при отсутствии простого аналитического выражения. При малых отклонениях от оптимального угла зависимость $x_{hit} - x_D$ также демонстрирует практически линейное поведение, но с коэффициентом, зависящим от показателей преломления и геометрии. При приближении к критическому углу модель перестает работать (возникает полное внутреннее отражение), что соответствует физике явления.

3.  **Адекватность.** Модель адекватно описывает как идеальный случай отражения (имеющий аналитическую проверку), так и более сложный случай преломления, где численное решение является единственным практическим способом нахождения вариационной переменной. Результаты физически непротиворечивы и позволяют определить требуемые параметры с наперед заданной точностью.
